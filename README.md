# Thesis - Assessing L2 English: Pausing and Lengthening Patterns as Proficiency Indicators in the ELSA Speak Application

Scripts for data analysis:

1. Normalizing pausing annotations - making them all be annotated as “__” (just two underscores)
2. Counting occurrences of silent pauses ( __ ) and printing results
3. Counting occurrences of filled pauses ( _x_ ) and printing results
4. Counting occurrences of lengthenings ( _y_ ) and printing results
5. Measuring and printing audio durations (using the Librosa library)
6. Word counting and printing results
7. Graph generation script for Speech Rate (WPM)
8. Graph generation script for disruptive pauses + lengthenings

Note: Generative AI was used in the process of creating these scripts. They were manually reviewed.
